# Spotify Clone

A responsive Spotify Clone built using **HTML5** and **CSS3**. This project recreates the Spotify web interface to practice responsive layouts, Flexbox, and modern UI design.

---

## Features

- Responsive Spotify-inspired layout
- Sidebar navigation
- Music cards and playlists
- Music player UI
- Clean and modern interface

---

## Technologies Used

- HTML5
- CSS3

---

## Concepts Used

- Semantic HTML
- Flexbox
- Responsive Design
- CSS Positioning
- CSS Styling
- Icons & Images
- Layout Design
